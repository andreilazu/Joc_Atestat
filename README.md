# Joc_Atestat
Atestat 2025 la Informatica

Joc Atestat is a challenging platformer game where players navigate through different worlds by completing parkour challenges. With each level, the environment becomes more distorted and complex, offering unique challenges that test your movement skills.

The game is divided into three levels:
Normal World – The starting level with a balanced and straightforward parkour experience.
Disturbed World – A twisted version of reality where the environment changes, creating more obstacles and chaos.
Desert World – A harsh, barren landscape where surviving the parkour challenges is as difficult as overcoming the elements.

Controls
Arrow keys: Move the player
Spacebar: Jump

Installation
Clone the repository: git clone https://github.com/andreilazu/Joc_Atestat.git
Run the game: npm start
